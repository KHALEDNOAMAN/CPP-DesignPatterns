# C++ Design Patterns

A comprehensive catalog of C++ design patterns with UML descriptions and use cases.

## Overview
20+ design patterns with real-world embedded systems examples

## Features
Creational (Singleton, Factory, Builder), Structural (Adapter, Facade), Behavioral (Observer, Strategy, State), Concurrency, Embedded-specific patterns

## Architecture
Organized by pattern category with independent examples

## Tech Stack
C++17, CMake

## How It Works
Each pattern has a header + implementation + example with detailed comments

## Installation
Clone, mkdir build && cd build && cmake .. && make

## Usage
Run any pattern example: ./build/singleton_example

## Project Structure
creational/, structural/, behavioral/, concurrency/, embedded_patterns/, modern_cpp/

## Screenshots
Example pattern output

## Future
Thread-safe patterns, C++20 concepts integration, benchmark comparisons
